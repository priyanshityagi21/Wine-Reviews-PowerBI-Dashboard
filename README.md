# 🍷 Beyond the Bottle

An interactive Power BI dashboard that explores global wine trends using over 130,000 wine reviews.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Dashboard Pages

### Executive Overview
- KPIs
- Average Price
- Average Rating
- Top Wine-Producing Countries

### Geographical Analysis
- Country & Province Analysis
- Reviewer Distribution
- Price vs Rating
 

## Key Features

- Dynamic DAX Measures
- Interactive Slicers
- Drill-down Matrix
- Bookmarks
- Responsive Navigation
- Custom Theme

## Business Insights

- Premium wines are concentrated in specific provinces.
- Reviewer activity varies across countries.
- Rating and price are not always strongly correlated.
- Wine varieties differ significantly by region.
